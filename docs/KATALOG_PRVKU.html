📝 1. Zdroje dat (Sources)

Zdroje dat generují vstupní data pro simulaci. Všechny zdroje mají výstupní port.

📝
Textový editor
TextSourceNode
Zadejte libovolný text jako zdroj dat pro simulaci.
Výstupní port
TEXT
Kategorie
Zdroje (Sources)
⚙️ Parametry:
text
Typ: TEXT | Výchozí: "Hello World!" | Textová data pro odeslání
encoding
Typ: VOLBA | Výchozí: utf-8 | Možnosti: utf-8, ascii, utf-16, iso-8859-2 | Znaková sada
🎲
Náhodný generátor
RandomSourceNode
Generuje náhodná binární data s nastavitelnou entropií.
Výstupní port
BINARY
Kategorie
Zdroje (Sources)
⚙️ Parametry:
length
Typ: INTEGER | Výchozí: 100 | Rozsah: 1-10000 | Počet bajtů k vygenerování
entropy_target
Typ: FLOAT | Výchozí: 4.0 | Rozsah: 0.0-8.0 | Krok: 0.5 | Cílová entropie v bitech/bajt (0=konstantní, 8=random)
seed
Typ: INTEGER | Výchozí: 0 | Rozsah: 0-999999 | 0 = bez seedu (náhodné)

Kategorie

Typ: TEXT | Výchozí: "255" | Číselná hodnota jako řetězec
base
Typ: INTEGER | Výchozí: 10 | Rozsah: 2-36 | Základ číselné soustavy
label
Typ: TEXT | Výchozí: "" | Volitelný popisek pro zobrazení
