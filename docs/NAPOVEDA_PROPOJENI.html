1. Základy propojování

1.1 Jak propojit dva prvky

Prvek A ──────▶ Prvek B

(output) ──────────▶ (input)
Postup:
  1. Klikněte na výstupní port (kolečko na pravé straně prvku) - obarví se žlutě
  2. Táhněte myší - vytvoří se přechodová křivka (Bézierova křivka)
  3. Uvolněte na vstupním portu (kolečko na levé straně cílového prvku) - propojení je hotové
  4. Stiskněte Escape nebo klikněte jinam pro zrušení

1.2 Pravidla propojování

Pravidlo Popis Příklad
Směr Vždy output → input Výstup zdroje → Vstup kompresoru
Žádné smyčky Nemůžete propojit prvek sám se sebou Node A → Node A ❌
Jeden vstup Vstupní port může mít jen jednu spojení Nelze Node A → Node B a zároveň Node C → Node B
Více výstupů Výstupní port může mít mnoho spojení Node A → Node B, Node A → Node C ✓
Kompatibilita dat Porty musí být kompatibilní TEXT → BINARY ✓, AUDIO → TEXT ❌

4. Užitečné kombinace

🎯 Základní: Text → Komprese → Kanál → Dekomprese → Text

📝 Text ──→ 🌳 HuffmanEnc ──→ 📡 BSK ──→ 🌳 HuffmanDec ──→ 📝 Text

Co se stane: Text se komprimuje, projde šumovým kanálem a dekomprimuje se.

Co pozorovat: Kompresní poměr, počet chyb, entropii před/po kompresi.

🎯 Základní: Číslo → Převod soustavy

🔢 Číslo (255₁₀) ──→ 🔀 BaseConv (10→2) ──→ 📊 Analyzátor

Výstup: "11111111" (binární)

Možné varianty: 10→8, 10→16, 2→16, atd.

⚙️ Středně pokročilý: Komprese + ECC (oprava chyb)

📝 Text ──→ 🌳 Huffman ──→ 🔴 Hamming(7,4) ──→ 📡 BSK ──→ 🔴 HammingDec ──→ 🌳 HuffmanDec ──→ 📝 Text

Výhoda: Kombinace komprese + ECC je velmi účinná pro přenos přes šumové kanály.

🔥 Pokročilý: Kompletní komunikační řetězec

📝 "Hello" ──→ 🔤 UTF-8Enc ──→ 🌳 Huffman ──→ 🔴 Hamming(7,4) ──→ 📡 BSK ──→ 🔴 HammingDec ──→ 🌳 HuffmanDec ──→ 🔤 UTF-8Dec ──→ 📝 Výstup

Postup transformace:

  1. Text → UTF-8 kódování → BINARY (40 bitů)
  2. BINARY → Huffman komprese → HUFFMAN (25 bitů, poměr 1.6:1)
  3. HUFFMAN → Hamming kódování → BINARY (35 bitů, přidáno 10 bitů ECC)
  4. BINARY → BSK kanál (p=0.05) → BINARY (možná s chybami)
  5. BINARY → Hamming dekódování → BINARY (opraveny chyby)
  6. BINARY → Huffman dekomprese → BINARY (40 bitů)
  7. BINARY → UTF-8 dekódování → TEXT ("Hello")

📊 Srovnání kompresních algoritmů

📝 Text ──┬─→ 📏 RLE ──→ 📊 CompRatio
├─→ 🗜️ LZ77 ──→ 📊 CompRatio
└─→ 🌳 Huffman ──→ 📊 CompRatio

Co pozorovat:

  • RLE: Dobré pro opakující se data (AAAAAA)
  • LZ77: Dobré pro text s opakujícími se vzory
  • Huffman: Dobré pro data s nerovnoměrnou frekvencí

5. Příklady scénářů

📚 Scénář 1: Procvičení převodů soustav

Krok 1: Přetáhněte 🔢 Číslo na plátno
Krok 2: Nastavte: value=255, base=10
Krok 3: Přetáhněte 🔀 BaseConv
Krok 4: Nastavte: from_base=10, to_base=2
Krok 5: Propojte je a spusťte simulaci
Výsledek: Číslo 255 se převede na "11111111" (binární)

📊 Scénář 2: Porozumění entropii

Krok 1: Přetáhněte 🎲 Random
Krok 2: Nastavte: entropy_target=0.0 (všechna "A")
Krok 3: Přetáhněte 📊 Entropie
Krok 4: Propojte a spusťte
Výsledek: H(X) ≈ 0.0 bitů (všechna data stejná)

Experimenty:

  • entropy_target=8.0 (náhodná data) → H(X) ≈ 8.0 bitů
  • entropy_target=4.0 (písmena a číslice) → H(X) ≈ 5.5 bitů

🔧 Scénář 3: Chyby v komunikaci

Krok 1: Vytvořte text: "Test"
Krok 2: Přidejte 🔤 UTF-8 Enc
Krok 3: Přidejte 🔴 Hamming(7,4) Enc
Krok 4: Přidejte 📡 BSK s error_prob=0.1
Krok 5: Přidejte 🔴 Hamming(7,4) Dec
Krok 6: Přidejte 📊 BER Meter
Výsledek: Hamming opraví většinu chyb (1 bit na 7), BER po opravě bude mnohem nižší

6. Tipy a triky

💡 Rychlé propojování

Můžete táhnout z výstupu na vstup i naopak. Systém automaticky rozpozná směr.

🔄 Paralelní zpracování

Můžete porovnávat různé vstupy nebo algoritmy současně:

📝 Text1 ──→ 🌳 Huffman ──→ 📊 CompRatio
📝 Text2 ──→ 🌳 Huffman ──→ 📊 CompRatio

🔗 Zřetězení analyzátorů

Každý analyzátor přidá další metriky do historie paketu:

📝 Text ──→ 🌳 Huffman ──→ 📊 CompRatio ──→ 📊 Entropie ──→ 📈 Histogram

⚙️ Užitečné parametry

  • BSK kanál: error_prob (0.0 - 1.0) - pravděpodobnost chyby
  • LZ77: window_size (128 - 32768) - velikost vyhledávacího okna
  • Huffman: Automaticky vypočítá optimální kódy
  • BaseConv: from_base, to_base (2 - 36)

7. Řešení problémů

❌ Nemůžu propojit dva prvky

Příčiny:

  • Nekompatibilní datové typy - zkontrolujte barvy portů
  • Už je spojení - vstupní port může mít jen jedno spojení
  • Smyčka - nemůžete propojit prvek sám se sebou

Řešení: Klikněte na port pro zobrazení tooltipu s důvodem

❌ Spojení se neobjeví

Příčiny:

  • Oba prvky nejsou na plátně
  • Porty jsou skryté (přiblížili jste se příliš)
  • Chyba v validaci

Řešení: Přiblížte/oddalte pohled (scroll nebo Ctrl+scroll)

❌ Simulace nefunguje

Příčiny:

  • Chybí vstupní zdroj
  • Prvky nejsou propojené
  • Chyba v algoritmu

Řešení: Zkontrolujte, že máte zdroj (📝, 🎲, atd.) a spojení
